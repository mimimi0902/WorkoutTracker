# 学習記録

## Gitについて
- Gitはファイルの変更履歴を管理するツール。
- git add：変更したファイルを登録する。
- git commit：変更履歴を保存する。
- git push：変更内容をリモートリポジトリに送信する。

## GitHubについて
- GitHubはGitのリポジトリをオンラインで管理できるサービス。
- 作成したプログラムを保存・共有できる。

## Reactについて
- ReactはWebアプリの画面を作るためのJavaScriptライブラリ。
- コンポーネントを組み合わせて画面を作成する。

## Viteについて
- ViteはWebアプリの開発を支援するツール。
- npm run devで開発サーバーを起動できる。
