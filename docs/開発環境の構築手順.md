
## 1. Node.jsのインストール

1. Node.js公式サイト（https://nodejs.org/）にアクセスする。
2. Windows用のインストーラーをダウンロードする。
3. インストーラーを起動する。
4. 基本設定は変更せず、Nextを押して進める。
5. インストール完了後、VS Codeを再起動する。
6. ターミナルで以下のコマンドを実行する。

`node -v`

バージョンが表示されればインストール成功。

確認したバージョン：v26.13.1
## 2. ReactとViteの環境構築

1. VS CodeでC:\WorkoutTrackerフォルダーを開く。
2. VS Codeのターミナルを開く。
3. 以下のコマンドでReactアプリを作成する。

`npm create vite@latest . -- --template react`

4. 画面の指示に従って設定する。
5. 必要なパッケージをインストールする。

`npm install`

6. 以下のコマンドで開発サーバーを起動する。

`npm run dev`

7. ブラウザで http://localhost:5173/ を開く。

「Vite + React」の画面が表示されれば成功。

## 3. 使用技術

- 実装言語：JavaScript
- 画面構成：HTML
- デザイン：CSS
- ライブラリ：React
- 開発ツール：Vite
